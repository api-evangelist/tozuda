# Tozuda

> Tozuda is a Philadelphia-based safety technology company that makes mechanical (non-electronic) head impact indicators for helmets. The patented indicator changes from clear to red when a helmet sustains an impact exceeding a set G-force threshold, making hidden helmet damage visible to workers, athletes, and safety inspectors. Tozuda is a Techstars portfolio company. It does not currently publish a public API or developer program.
